# Второй аудит корректности 1.0.1 → 1.0.2

Дата: 2026-11-04. Четыре отдельных аудитора-агента со свежим контекстом проверяли
одну зафиксированную сборку 1.0.1 (SHA-256 `29DB377D…6C84A5D`), не изменяя
исходники, тесты и документацию. Все пробы — в `build/audit2/<область>/`.
Каждая находка затем воспроизведена повторно и исправлена с регрессией.

**Ограничение независимости:** агенты основаны на той же модели, что и разработчик.
Это внутренний повторный аудит со свежим контекстом, а не внешний аудит людьми.

## Охват

| Область | Объём проверки |
|---|---|
| Frontend | ~350 целевых случаев, ~16 000 мутантов fuzz-генерации, лимиты и производительность |
| Код SPIR-V и GPU | Все opcodes/операнды против grammar; 256×40 скалярных операций; ~5 600 случайных выражений O0/O1; 30 случайных программ управления потоком; atomics, barriers, images, sampling на GPU |
| ABI | 940 случайных шейдеров (2 875 типов элементов, 940 push-блоков); 852 790 проверок `SizeOf`/смещений в Delphi; 175 форм на GPU |
| Исходники/сборка/CLI | Поиск, циклы, бюджеты, provenance, кеш, коллизии путей (hard links, junctions, UNC, Unicode-регистр), API |

Ошибок в расчёте `std430`, ложных cache hit и утечек абсолютных путей не найдено.

## Подтверждённые и исправленные находки

вычисляется раньше внутреннего (раньше было обратное). Выход ADS-путей
(`file:stream`) теперь отвергается, сообщение об отсутствующем входном файле понятнее.

## Повторная проверка

```powershell
.\scripts\test.ps1
python .\tests\vulkan_smoke.py --require-shared-cpu
python .\tests\audit_numeric_gpu.py --count 256
python .\tests\audit_numeric_gpu.py --count 512 --seed 0xC0FFEE
```

- **844** CLI/API/ABI/source/cache проверки, включая `tests/audit2.ps1`.
- **50** Vulkan dispatches, включая twin-тип shared, typed constants и порядок селекторов на O0/O1.
- **2 304** результата differential-аудита целочисленной арифметики.
- **8 526** векторов округления литералов (`tests/FloatLiteralCheck.dpr`,
  генератор `tests/float_literal_vectors.py`).
- Повторный прогон собственных repro-скриптов аудиторов против новой сборки.

## Остаточные риски

- Только AMD Radeon RX 9070 XT, Delphi 13 Win64; NVIDIA/Intel и validation layers не проверены.
- Fuzzing ограничен по объёму; полнота не доказана.
- Худший допустимый случай анализа инициализации (4 096 переменных, 150 000 операторов,
  ~4 MiB) компилируется ~6 с — ограничено, но не мгновенно.
- Race freedom, завершение и межгрупповая синхронизация не доказываются компилятором.
